# Promotional Text

field can be updated any time without submitting a new build — good place to
seasonally refresh copy (e.g. "back to school").

    Learn to write letters and simple words with guided strokes, instant scoring, and fun celebrations — for iPad and iPhone.

## Option B — parent-facing (121 chars)

    Give your child a fun, guided path to confident handwriting — trace letters and words with instant, encouraging feedback.

## Option C — kid-facing / playful (125 chars)

    Trace letters, spell simple words, and earn stars! Fun, guided handwriting practice with instant feedback for little writers.
