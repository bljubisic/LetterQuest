# LetterQuest ✏️

A universal iPhone/iPad app that teaches children to write letters and
simple words using a finger or Apple Pencil. The child draws on a PencilKit
canvas; a four-signal scoring pipeline evaluates the drawing and gives
real-time, encouraging feedback.

## Features

- **Uppercase, lowercase, and word practice** — an animated "Watch me draw"
  demonstration precedes each letter, followed by guided tracing with
  dotted stroke paths, numbered starting points, and baseline/height
  guides. Word practice (simple three-letter words) unlocks once a child
  completes an alphabet's uppercase and lowercase letters.
- **Four-signal handwriting assessment** — stroke order (Dynamic Time
  Warping), shape (bitmap IoU against a template), proportion (guideline
  geometry), and smoothness (angular jitter / speed variance), combined
  into one score with per-signal feedback.
- **Multiple alphabets** — English (Latin) is free and installed by
  default; additional packs (starting with Serbian Cyrillic) are
  purchasable one-time in-app purchases via StoreKit 2, with a Switch
  Alphabet screen to pick which owned alphabet is active.
- **Progress & achievements** — a Progress screen tracks per-letter and
  per-word completion, attempt history, best scores, and achievement
  badges (First Letter, Halfway There, Alphabet Champion, Wordsmith).
- **Parental gate** — commerce actions (buying or restoring alphabet
  packs) sit behind a "Parents Only" challenge that can't be disabled or
  bypassed, per App Store Review Guideline 1.3 (Kids Category).
- **Accessible by design** — full VoiceOver support and Dynamic Type
  throughout.
- **Privacy-first** — no accounts, no network calls, no analytics or
  advertising SDKs. All progress is stored locally via `UserDefaults`.
  See the published [Privacy Policy](https://bljubisic.github.io/LetterQuest/privacy-policy.html).

## Requirements

- Xcode 16+ (Swift 5.9 for the app target, Swift 6.0 for the test target)
- iOS 17.0+ (iPhone and iPad)
- [XcodeGen](https://github.com/yonaskolb/XcodeGen) to generate the Xcode project
- Swift Package Manager (resolved automatically by Xcode) for the one
  external dependency, [RxSwift](https://github.com/ReactiveX/RxSwift)

## Getting Started

```bash
git clone git@github.com:bljubisic/LetterQuest.git
cd LetterQuest
xcodegen generate
open LetterQuest.xcodeproj
```

Run on an iPad or iPhone simulator/device from Xcode (Product → Run). There
is no CLI-only build target — the project is generated by XcodeGen from
`project.yml`, and every subsequent edit to `project.yml` requires re-running
`xcodegen generate`.

### Running tests

Tests use the [Swift Testing](https://developer.apple.com/documentation/testing)
framework (`import Testing`, `@Test`/`#expect`) for unit tests, and XCTest
for UI flow tests. Run them in Xcode via Product → Test (⌘U), or from the
command line:

```bash
xcodebuild -project LetterQuest.xcodeproj -scheme LetterQuest \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro' test
```

## Architecture

MVVM with protocol-oriented dependency injection — every layer exposes a
protocol, and concrete types are wired together once in `LetterQuestApp.swift`.
No singletons or service locators.

```
LetterQuestApp (entry point, DI root)
  └── AppRouter               — NavigationPath, driven via PublishRelay<AppRoute>
  └── AlphabetRepository      — installed/available alphabets, entitlement-aware
  └── LetterRepository        — letters for the active alphabet
  └── WordRepository          — curated per-alphabet word lists
  └── ProgressRepository / WordProgressRepository — UserDefaults-backed history
  └── SettingsRepository      — sound/haptics/difficulty/active-alphabet
  └── PurchaseService (StoreKit 2) + AlphabetEntitlementProviding
  └── HandwritingAssessor     — four-signal scoring pipeline
        ├── DTWMatcher          (35%) — stroke path via Dynamic Time Warping
        ├── ShapeAnalyzer       (35%) — bitmap IoU against a template
        ├── ProportionChecker   (20%) — guideline geometry
        └── SmoothnessAnalyzer  (10%) — angular jitter / speed variance
```

- **Reactive layer**: repositories return `Single`/`Completable` (RxSwift);
  ViewModels expose `@Published` properties as a SwiftUI-friendly bridge
  over the Rx pipelines. Scoring runs off the main thread inside
  `Single.create`.
- **Navigation**: `AppRoute` is a `Hashable` enum used as `NavigationPath`'s
  element type. Home itself is a bottom-tabbed screen (uppercase / lowercase
  / words, the last shown once unlocked) rather than a pushed route.
- **Immutability**: models (`Letter`, `ChildProgress`, `WordProgress`, etc.)
  are read-only structs, updated through `Lens<Whole, Part>` values and the
  `|>` pipe-forward operator rather than in-place mutation.
- **Views** are generic over their ViewModel protocol
  (`struct HomeView<VM: HomeViewModelProtocol>`), so previews and tests can
  inject a lightweight mock instead of the real ViewModel.

## Directory Structure

```
LetterQuest/
  App/                    — entry point, ScreenshotDemo, E2ETestSupport
  Navigation/              — AppRoute, AppRouter
  Models/                  — Letter, Word, ChildProgress, Alphabet, ...
    Alphabets/             — per-alphabet letter/stroke definitions (Latin, Cyrillic)
    StrokeTemplates/       — path-building helpers for stroke templates
    Protocols/
  ViewModels/              — one per screen (Home, Practice, Progress, Store, ...)
    Protocols/
  Core/
    Assessment/            — HandwritingAssessor + its four signal analyzers
    Repositories/          — Alphabet/Letter/Word/Progress/Settings repositories
      Protocols/
    Purchasing/            — StoreKit 2 purchase service + entitlement provider
    Lenses/                — generic Lens<Whole, Part>
    Sound/, Haptics/
  Views/
    Home/, Learn/, Practice/, Progress/, Settings/, Store/, SwitchAlphabet/,
    Words/, Onboarding/, Shared/ (LetterCard, WordCard, AlphabetCard, ParentalGateView, ...)
  Resources/               — Info.plist, StoreKitConfiguration.storekit, sounds

LetterQuestTests/          — Swift Testing unit tests (ViewModels, repositories, models)
LetterQuestUITests/        — XCTest UI flow tests (onboarding, practice, settings, store)

AppStore/                  — App Store Connect metadata (description, privacy
                             policy source, review notes, age rating, in-app
                             purchase setup guide) and screenshots
docs/                      — GitHub Pages site (published privacy policy)
scripts/                   — App Store screenshot capture automation
```

## In-App Purchases

Alphabet packs beyond the free English one are non-consumable purchases via
StoreKit 2. `LetterQuest/Resources/StoreKitConfiguration.storekit` provides a
local sandbox for development and simulator testing; see
[`AppStore/in-app-purchases.md`](AppStore/in-app-purchases.md) for the
step-by-step process to create the matching live product in App Store
Connect.

## App Store Submission

Store-listing copy, the privacy policy, review notes, and the age-rating
questionnaire answers live under [`AppStore/`](AppStore/), kept in sync with
the app's actual behavior as features change.
